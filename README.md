## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/asaini9926/Oxford-Landscape.git
   cd Oxford-Landscape
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🌐 GitHub Pages Deployment

This repository is configured with automated GitHub Pages deployment via **GitHub Actions** (`.github/workflows/deploy.yml`).

### Setup in GitHub (One-time):
1. Go to your repository on GitHub: `https://github.com/asaini9926/Oxford-Landscape`
2. Navigate to **Settings** > **Pages**
3. Under **Build and deployment** > **Source**, select **GitHub Actions**
4. Any push to `main` will automatically build and publish the latest version to:
   👉 **https://asaini9926.github.io/Oxford-Landscape/**
